# BankTrace: Fluorocarbon Bank Intelligence for Carbon Markets

> A data service that maps where produced-but-not-yet-emitted HCFCs and HFCs are 'banked' in installed equipment (fridges, AC units, foams) by region and life-cycle stage, so refrigerant recovery projects can target the highest-impact stockpiles and generate verifiable carbon credits.
